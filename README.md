# 有数 · 个人银行 AI 助手

用中文查账单、安排预算、管理模拟账户，联动证券、外卖和旅行演示站。前端使用 Vue 3，后端使用 FastAPI。

**本项目仅供本地演示，资金、交易和短信都是模拟数据。** AI 对话需要你自己的模型接口与密钥，调用费用由接口服务商收取。

第一次使用请顺序阅读；文字体验不需要配置语音、人脸或飞书。

## 首次启动（Windows）

### 1. 安装工具

| 工具 | 安装方式 | 用途 |
| --- | --- | --- |
| Node.js | 打开[官方下载页](https://nodejs.org/en/download)，选择 Windows 安装包，按默认选项安装。需要22.12+，推荐24.x LTS | 安装和构建网页，npm随它安装 |
| uv | 从开始菜单打开 **PowerShell**，运行下方命令 | 准备Python和项目依赖 |

```powershell
winget install --id astral-sh.uv -e
```

安装后，**关闭PowerShell，再重新打开**，逐行检查：

```powershell
node --version
npm.cmd --version
uv --version
```

三条命令都显示版本号即可继续。无需手动安装Python或创建虚拟环境。没有`winget`时，按[uv官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)安装。

### 2. 下载项目，打开正确的文件夹

1. 打开[项目仓库](https://github.com/TFboy1/AI-banking)，点击 **Code → Download ZIP**。
2. 下载后解压，进入能看到`README.md`、`pyproject.toml`、`frontend`和`scripts`的文件夹。这就是**项目根目录**。
3. 在资源管理器顶部的地址栏输入`powershell`，按回车。新窗口会在该目录打开。

后文命令默认在这个窗口执行。**一次复制一个代码框，等执行结束再继续；不用复制终端前面的`PS D:\...>`。** 不要在压缩包中直接运行。

已安装Git的用户，也可以用以下命令代替下载ZIP：

```powershell
git clone https://github.com/TFboy1/AI-banking.git
cd AI-banking
```

### 3. 安装项目依赖

在项目根目录执行：

```powershell
uv python install 3.11
uv sync --frozen --python 3.11 --extra speech --extra face --link-mode hardlink
```

uv会创建`.venv`，按锁定版本安装依赖。首次下载包含语音和人脸运行库，体积较大；等命令结束、重新出现输入提示后再继续。

依赖优先使用uv全局缓存和硬链接；缓存与项目跨磁盘时可能退回复制，不影响使用。语音、人脸的模型文件需要另行下载，先不下载也能使用文字功能。

### 4. 配置AI模型

1. 在项目根目录复制`.env.example`，将副本重命名为 **`.env`**。
2. 如果已有`.env`，直接编辑，保留现有设置。
3. 用记事本打开`.env`，修改以下三项，保存为UTF-8：

```dotenv
LLM_BASE_URL=https://你的接口服务地址/v1
LLM_API_KEY=你的接口密钥
LLM_MODEL=你的模型名称
```

这些值从模型服务商的控制台获取，**不能照抄示例文字**：

| 配置 | 填写说明 |
| --- | --- |
| `LLM_BASE_URL` | 兼容Chat Completions的接口根地址；保留服务商要求的`/v1`等前缀，末尾不要加`/chat/completions` |
| `LLM_API_KEY` | 你在服务商处创建的API密钥 |
| `LLM_MODEL` | 服务商提供的准确模型名称，不是自定义昵称 |

其他配置先保持默认。暂时没有接口也可以继续启动、查看模拟账户，聊天会提示模型未配置。设置中的“已配置”只代表配置齐全，实际联网在发送请求时检查。

密钥只在后端使用；不要分享或提交自己的`.env`。

### 5. 导入演示账号

**新安装推荐在第一次启动服务前执行**，这样登录后就有余额、联系人、持仓和账单：

```powershell
uv run --frozen --extra speech --extra face python scripts/load_demo.py
```

看到`Demo restored`表示成功。

| 项目 | 内容 |
| --- | --- |
| 登录手机号 | `11111111111` |
| 四位应用与交易密码 | `0000` |
| 登录验证码 | 点击网页“获取验证码”后，在网页提示中查看 |

导入的是仓库内的脱敏快照，不包含API密钥、人脸、登录状态或既有交易授权。

> [!IMPORTANT]
> 如果提示`Existing account data found`，说明已有账号，脚本为保护数据拒绝覆盖。已有数据就跳过导入，使用原账号；不要为了重试而删除`data`。不导入而直接注册的新账号初始为空，不能直接照搬转账示例。

### 6. 启动主站

```powershell
.\scripts\start.ps1
```

脚本会检查Python依赖、安装网页依赖、构建网页，再启动服务。首次运行需要联网下载，请保留窗口。

看到类似日志后，才表示启动完成：

```text
Application startup complete.
Uvicorn running on http://127.0.0.1:8000
```

在浏览器**地址栏**输入[http://127.0.0.1:8000](http://127.0.0.1:8000)。不必额外启动前端服务器。

如果提示“禁止运行脚本”，在当前窗口执行以下命令后重试，仅影响这个PowerShell窗口：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\start.ps1
```

服务运行期间会一直占用窗口，这是正常的。需要输入其他命令时，另开一个位于项目根目录的PowerShell窗口。

## 开始体验

### 登录并查看账户

1. 导入过演示账号时，选择“已注册？手机号登录”或“使用手机号短信登录”，输入`11111111111`。
2. 点击“获取验证码”，把**网页显示的六位验证码**填回输入框，再登录；这里不是填写四位密码`0000`。
3. 如果直接出现解锁页，输入`0000`。这是导入账号的应用密码。
4. 出现人脸引导时可选“暂时跳过”，继续文字体验。
5. 进入主界面后，打开顶部“模拟账户”查看余额；打开“联系人”查看收款对象。脱敏姓名可点击眼睛图标查看。

没有导入演示账号时，按页面完成注册和四位密码设置；联系人、人脸可稍后添加。各手机号的账户数据独立保存。

### 先查询，再转账

在底部聊天框一次发送一条，等当前请求结束再继续：

| 想体验什么 | 可以这样说 |
| --- | --- |
| 账户查询 | 查询我的账户余额。 |
| 账单分析 | 分析最近三个月的支出，按类别展示。 |
| 资金预演 | 我想买台6000元的电脑，下个月至少留3000元生活费，先帮我预演，不要付款。 |
| 订阅查询 | 查看我的订阅和下次扣费日期。 |
| 理财查询 | 比较现有理财产品，先不要购买。 |

试转账时，先从“联系人”选一个**实际存在**的演示收款人，再发送“给某某转100元，备注测试”：

1. 同名或多卡时，按提示明确收款人和银行卡。
2. 核对确认卡上的收款方、金额、备注，再点击确认。
3. 按提示选择付款账户，输入四位交易密码；导入账号初始为`0000`。
4. 要求短信时，点击获取验证码，填写本次模拟交易短信。已绑定并启用人脸的账号，还需按页面要求刷脸。
5. **看到执行回执，再检查余额和流水**。建议、预演和待确认卡都不表示已付款。

确认卡15分钟有效，重复确认已完成操作不会重复扣款。修改参数、付款账户或时间后需重新验证。支持定时的操作可在验证窗口选择“定时执行”：现在只授权，到期仍会复核条件。

发送新消息会撤销当前会话旧需求中尚未确认的操作；切换会话不会自动撤销原卡片。同一账号各会话共用余额和持仓。组合任务中途失败时，已成功的操作保留，不会整体自动回滚。

## 打开证券、外卖、旅行和管理端

**先保持主站运行。** 在项目根目录另开PowerShell，每个站点使用一个窗口；只启动你要体验的站点。

| 站点 | 在新窗口执行 | 浏览器地址 |
| --- | --- | --- |
| 证券 | `.\scripts\start-securities.cmd` | [http://127.0.0.1:8001](http://127.0.0.1:8001) |
| 外卖 | `.\scripts\start-food.cmd` | [http://127.0.0.1:8002](http://127.0.0.1:8002) |
| 管理员与客服 | `.\scripts\start-admin.cmd` | [http://127.0.0.1:8003](http://127.0.0.1:8003) |
| 旅行 | `.\scripts\start-travel.cmd` | [http://127.0.0.1:8004](http://127.0.0.1:8004) |

证券、外卖、旅行分别登录并关联：

1. 在对应站点输入测试手机号，用**该网页显示的模拟短信**登录。
2. 回到有数主站，打开齿轮“设置 → 连接其他平台”，点击**生成同步码**。
3. 返回对应站点，在关联账户处填入该码，完成连接。
4. 回到主站发起业务。资金操作仍由主站确认与验证。

同步码5分钟有效，每个平台可使用一次；重新生成会使旧码失效。恢复演示账号后也要重新关联。管理端独立登录，初始本地演示密码是`000000`，与四位交易密码不同；可处理客服、解锁审核及审计查询。

## 下次启动、关闭与数据保存

**下次启动**可跳过已有的网页构建：

```powershell
.\scripts\start.ps1 -SkipBuild
```

更新项目或修改过前端后，用不带`-SkipBuild`的启动命令重新构建。

**关闭服务：** 回到各服务窗口按`Ctrl+C`；若询问是否终止批处理，输入`Y`并回车。只关闭浏览器不会停止服务。修改`.env`后也需停止并重启主站。

**保存数据：** 默认账户和业务数据在`data`，重启会保留。备份前停止全部服务，将`data`、实际配置的独立审计见证目录及`.env`一并妥善备份；自定义路径时以配置为准。不要把本地数据库、凭据和密钥上传公开仓库。

## 常见问题

| 现象 | 处理办法 |
| --- | --- |
| `uv`、`node`或`npm`无法识别 | 重新打开PowerShell并检查版本；仍失败则重新检查安装 |
| `npm.ps1`被阻止 | 手动运行时使用`npm.cmd`；启动脚本被阻止时按首次启动说明临时调整当前窗口策略 |
| 找不到启动脚本或`pyproject.toml` | 回到能看到`README.md`、`frontend`和`scripts`的项目根目录再运行 |
| 浏览器打不开8000端口 | 检查主站窗口是否还在运行，是否出现启动完成日志；地址要粘贴到浏览器地址栏 |
| 端口占用、`WinError 10048` | 检查是否已启动过该站点，直接使用原服务，或先用`Ctrl+C`停止旧服务 |
| 聊天提示模型未配置 | 确认文件名是`.env`而不是`.env.txt`，填写三项配置并重启；可在资源管理器“查看”中开启“文件扩展名” |
| 模型超时、401/403或请求失败 | 核对接口地址、密钥、模型名、额度与网络；“已配置”不代表请求已通过 |
| 模型只说话、不调用工具 | 默认`auto`会尝试兼容；接口支持JSON响应时，可设置`LLM_TOOL_MODE=structured`后重启。纯文本接口不能保证可用 |
| 登录后没有钱、联系人或持仓 | 检查是否用已导入的`11111111111`登录；其他新账号初始为空，不要强行重复导入 |
| 提示交易暂停或账号锁定 | 按页面等待、重新认证或提交人工解锁申请；管理端可审核，重启不会清除保护状态 |
| 独立站打不开或同步失败 | 检查独立站和主站是否都运行，在独立站登录后重新生成同步码关联 |
| 安装依赖或下载模型失败 | 检查日志和网络，修复后重跑该步骤；不要通过删除`data`解决安装问题 |

以下是可选的模型配置，写入`.env`后重启生效，不需要就保持默认：

```dotenv
# auto：优先原生工具调用，再兼容JSON计划
# structured：直接使用JSON计划；native：只用原生工具调用
LLM_TOOL_MODE=auto

# 需接口支持；本项目把max映射为xhigh发送
# LLM_REASONING_EFFORT=max
```

## 可选：语音、人脸和飞书

### 语音输入

另开项目根目录的PowerShell，下载本地语音模型：

```powershell
uv run --frozen --extra speech --extra face python scripts/setup_speech.py
```

下载完成后重启主站，允许浏览器使用麦克风。电脑点击麦克风开始、再次点击停止；触屏设备长按录音、松手结束。文字只回填输入框，核对姓名和金额后再手动发送。模型约237MB，详见[语音说明](docs/speech.md)。

### 人脸验证

在项目根目录下载本地人脸模型：

```powershell
uv run --frozen --extra speech --extra face python scripts/setup_face.py
```

下载完成后重启主站，进入“设置 → 人脸验证”，按页面完成密码、模拟短信和摄像头录入。首次下载约43MB模型，与前面安装的运行库是两部分；文字体验可跳过录入。

总开关`FACE_ENABLED=false`可关闭人脸功能，修改后重启；仍按规则验证密码和短信。人脸仅用于演示比对，不代表法定实名验证。详见[人脸与交易验证](docs/face.md)。

### 飞书私聊

默认关闭，网页可独立使用。需要飞书应用权限与凭据，按[飞书配置说明](docs/feishu.md)配置。

## 开发与检查

只体验项目的用户读到这里即可。以下命令供修改代码时使用，默认从项目根目录开始。

### 代码在哪里

| 位置 | 内容 |
| --- | --- |
| `frontend/src/` | Vue页面和组件；主站入口`App.vue` |
| `backend/banking/main.py` | 主站接口与应用创建 |
| `backend/banking/agent.py` | AI工具调用、任务与确认流程 |
| `backend/banking/bank.py` | 银行业务工具 |
| `backend/banking/*_site.py` | 独立站应用 |
| `backend/tests/` | 后端自动化测试 |
| `scripts/` | 启动、导入、构建与检查脚本 |
| `resources/demo/demo-account.json` | 脱敏演示数据快照 |
| `docs/` | 详细功能说明及历史验证记录 |

### 修改网页时实时预览

先保持8000主站服务运行，在另一个终端执行：

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

打开[http://127.0.0.1:5173](http://127.0.0.1:5173)。这是主站开发预览，接口转发到8000；保存修改后网页会更新。按`Ctrl+C`停止，执行`cd ..`回到项目根目录。

### 构建和检查

修改网页后构建：

```powershell
cd frontend
npm.cmd run build
cd ..
```

检查后端代码并运行测试：

```powershell
uv run --frozen ruff check backend
uv run --frozen pytest -q
```

一次执行后端检查、测试和前端构建，可用`.\scripts\check.ps1`。自动化测试使用临时数据库和模型替身；网页交互请另行手动检查。

检查真实HTTP接口和事件推送：

```powershell
uv run --frozen python scripts/smoke_backend.py
```

配置模型后，可运行`uv run --frozen python scripts/smoke_model.py`检查真实模型联调；会产生实际模型请求和可能的费用，使用临时数据库，不确认资金变更。
