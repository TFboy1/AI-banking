# 独立证券站、自选同步与模拟买入

银行网址：http://127.0.0.1:8000/；证券网址：http://127.0.0.1:8001/。两站保持独立，没有相互导航入口。

## 使用方法

1. 在银行登录并解锁。两个网址均使用127.0.0.1，避免一个用localhost、另一个用127.0.0.1导致登录Cookie不一致。
2. 先在证券站使用手机号短信登录，演示手机号为`11111111111`；首次验证新手机号自动创建空账号，自选、关联和持仓按账号隔离。验证码通过右下角模拟短信弹窗展示，5分钟有效，连续输错5次失效。
3. 在银行“应用设置 → 证券账户同步码”点击生成，复制8位码；在证券站点击“连接有数账户”并输入同步码。匹配后才建立一对一连接，增删自选保存到当前证券账号。同步码5分钟有效、仅可用一次，重新生成后旧码失效；输入频率限制为每个来源每分钟10次。
4. 回银行对话：“查看我的证券自选”。购买时说明股票和数量，例如“买自选里的平安银行100股”或“自选全部每只一手”。没有数量应先追问。
5. 核对报价和确认卡，在支付窗口选择付款账户，输入支付密码和右下角模拟短信提供的验证码。
6. 证券站刷新“模拟持仓与成交”查看记录，也可以在银行询问证券持仓。

可以在投资账户点击“重新测评风险等级”，重新填写并确认问卷；确认前保留原等级。已有持仓保留，后续购买按照最新风险等级校验。

## 演示规则

- 全部股票在演示中统一定为R4；必须先自行完成相匹配的风险测评。系统不能代填问卷。
- 股票模拟买入始终为红色操作，密码和短信均必需，不因小额而免除。
- 演示数量为100股整数倍，每只最多100000股，每单最多20只，总额最多100万元。这是演示简化规则。
- 使用AKShare最近可用交易日的不复权收盘价，卡片展示行情日期和来源；不代表实时成交价。行情失败、旧缓存状态、日期超过10天或价格无效时拒绝报价。
- 报价5分钟有效，绑定用户和会话，单份报价只能成功成交一次。确认时重新检查风险、余额、卡片状态及报价。
- 只扣虚拟账户或虚拟银行卡余额；扣款、订单、持仓在银行SQLite同一事务中提交。重复确认返回已有回执，不重复扣款。
- 银行总资产中的股票按持仓成本计入；证券站“我的账户”按最近可用交易日收盘价单独计算估值及浮动盈亏，注明日期与来源；演示不计佣金税费。已支持在有数投资账户选择股票卖出。
- 不接真实券商、不真实下单。未连接、未确认或验证失败时不扣款。

## 接口与存储

证券站：`GET /api/securities/session`、`POST /api/securities/connect`、`POST /api/securities/disconnect`、`PUT /api/securities/watchlist`、`GET /api/securities/portfolio`。独立证券登录会话使用HttpOnly Cookie；自选按用户保存到`data/securities-users.sqlite3`。

银行生成同步码接口：`POST /api/securities/pairing-code`，必须已登录并解锁。证券连接请求必须携带8位`code`，不能仅凭浏览器银行登录状态连接。同步码只存哈希，不记录明文。

银行工具：`get_securities_watchlist`、`quote_stock_purchase`、`purchase_stock_basket`、`get_securities_positions`。银行数据库保存报价、模拟订单与持仓；多用户仍各用自己的数据库。

证券内部自选/报价接口及银行授权/持仓接口需要共享桥接密钥。默认自动生成`data/.securities-bridge-key`，禁止放入前端或提交仓库。两个服务在同一项目启动时共用此文件；服务分离部署时应配置相同密钥并使用HTTPS及网络访问限制。

行情仍可不登录直接浏览。生成同步码需要银行当前账户登录并解锁；证券登录并关联后，按固定的一对一关系读取持仓，无需共享银行登录。

## 独立账号与一对一关联

证券使用独立HttpOnly登录Cookie（`securities_auth`），银行登录状态不能代替证券登录。账号保存在`stock_users`，`stock_bindings`对银行标识和证券标识分别设置唯一约束；已有关联不能换绑，也不能给同一银行账号关联第二个证券账号。退出证券登录只注销会话，不删除关联、自选或持仓。

原版本按银行标识保存的自选会在该银行同步码首次正确关联时迁移，已有银行成交和持仓保持原位，不重复扣款。升级后需短信登录并用同步码重新建立关联。持仓通过受共享密钥保护的内部接口按绑定的银行标识读取，不受浏览器当前银行账号影响。

证券登录接口为`POST /api/securities/auth/sms`、`POST /api/securities/auth/login`和`POST /api/securities/auth/logout`。新账号没有自选、关联、持仓和订单，不自动导入浏览器其他账号的数据。行情保持公开只读。

## 股票卖出与盈亏

在有数“投资账户 → 我的理财”点击股票的“卖出股票”，填写100股整数倍和到账账户，生成真实行情报价后确认，并输入支付密码和模拟短信验证码。也可对话说明股票、股数和到账账户。报价5分钟有效；取消或校验失败不减少持仓、不入账。卖出不要求当前风险等级达到R4，但始终需要密码及短信验证。

部分卖出按当前平均持仓成本分摊成本，全部卖出移除持仓。到账、订单、持仓和回执在同一事务提交，重复确认不会重复到账。演示即时模拟结算，不限制交易日或买入当天卖出，不等同真实市场交易规则。

证券“我的账户”集中展示持仓、成交记录、总浮动盈亏和逐只盈亏百分率；浮动盈亏=估值−剩余买入成本，百分率=浮动盈亏÷剩余买入成本；累计已实现盈亏按全部卖出成交计算。行情无效或过旧时显示未估值，部分股票缺行情时不计算总估值及总浮动盈亏。
