# 可选定时交易

资金交易共用“立即执行／定时执行”选择，默认立即执行。支持联系人转账、本人账户和银行卡划转、理财申购与赎回、证券卖出、演示外卖订单、模拟消费、储蓄目标转存；添加银行卡也支持预约。股票买入不支持定时，旧的定时买入授权失效且不执行。查询、联系人资料编辑等不属于资金交易，不增加预约入口。

## 使用

- 在原有业务确认后进入支付密码窗口，选择执行方式；定时填写北京时间日期和时刻，最多提前365天。
- 现在选择资金账户并验证密码；原业务要求短信的，仍需短信。时间、付款账户、金额均参与验证码绑定。改动后重新获取验证码。
- AI 对话也可指定时间，各资金工具新增可选 `execute_at` 字段；未提供明确日期时刻时澄清，不能默认为立即交易。
- 模拟账户的“定时交易”列表默认收起，集中查看所有预约、失败原因和实际回执，可以取消未执行预约。
- 预约列表仅显示资金来源与交易类型、用途、时间、金额和取消按钮；已结束记录显示简短状态。需要修改时取消原预约，重新发起该业务并授权。

股票买卖只允许北京时间交易日09:30–11:30、13:00–15:00，午休、周末和节假日不执行交易；查询、行情展示和估值继续可用。报价、确认、最终资金变更均复核时间。卖出预约需选择有效交易时段，到期仍重新检查。当前内置2026年沪深交易所公布的休市安排；后续年度需要更新日历，未载入的年度默认禁止交易。

时段参考：https://english.sse.com.cn/start/trading/schedule/
2026休市安排：https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml

## 授权和资金

授权回执仅表示已同意未来执行，不是成交回执。授权时不扣钱、不冻结余额、不增加持仓、不创建外卖订单。到期后台重新验证安全状态、原会话、对象资料、资金账户、余额、业务限额、风险匹配与报价。

价格采用“授权价格和内容不变才执行”的规则，避免把原报价无条件用于未来交易。证券和外卖到期通过对应独立平台的报价接口重新取价，不直接延长过期报价：股数、单价、费用、菜品、地址等变化会停止。理财按后台到期净值复核；净值或份额条件变化同样停止。当前版本不提供随市价成交、限价容差或自动加价。

每次预约只执行一次；成交、资金流水、独立执行回执和预约终态在同一数据库事务中提交。重启或并发扫描不重复成交。变更密码、手机号、安全门槛或进入安全恢复周期后，旧授权失效。

后台需要运行；在执行时刻5分钟内重启可以补扫描，超过窗口停止并要求重新授权，不自动补扣。平台无法报价、商品下架、余额不足等条件失败会保留原因，不自动重试。

定时授权是当前任务的执行边界。其余 DAG 步骤不会把“授权成功”当成“已到账”继续执行，也不会在到期成交后自动续跑，需要用户之后继续发起需求。

## 实现

- `scheduled_actions.py`：共用时间校验、原业务快照、提前授权、外部报价复核。
- `scheduled_transfers.py`：复用持久化预约表、单次调度、取消、执行回执；兼容原定时转账。
- `bank.py`：仅为白名单资金工具扩展输入模型，继续由原业务处理器校验和执行。
- `agent.py`、`main.py`：确认窗口时间参数、短信绑定、服务端执行边界。
- `App.vue`、`ScheduledTransfers.vue`：统一交易方式选择及预约管理。

测试在隔离数据库运行，不使用演示账户资金；覆盖全部十类操作、提前不扣款、并发执行一次、过期报价重新获取、价格变化停止、验证码时间绑定及即时交易兼容。
