# 证券开收盘演示模式

- 独立证券网站一次读取20只测试股票的开盘价、收盘价，无需逐只点击。首次加载会补齐缺失数据。
- 数据来自证券服务的AKShare日行情接口；图表与历史表格仅展示开盘、收盘。
- 交易日盘中使用当天开盘价估值，收盘价显示“待收盘”；收盘后使用已获取的收盘价。未完成收盘更新的盘中缓存不能冒充收盘价。
- 后台缓存按北京时间工作日09:30和15:00两个节点失效。前台在节点后15秒请求一次，取消每30秒刷新；重新打开、买卖后更新持仓时复用同一时段行情。
- 页面关闭后不进行持续抓取；再次打开时读取当前节点数据。周末跳过，法定假日由上游实际交易日期体现，不伪造当天价格。行情请求失败保留上次可用价格，并展示日期、来源和缓存状态。
- 有数投资账户、账户分类中的投资金额、证券账户盈亏、模拟买卖报价统一使用相同的开收盘价格规则。成交成本不随估值变化；投资本金仍与日常收支分开统计。
- 行情缺失不会生成价格或扣款。所有买卖仍为模拟交易，继续要求原有确认、支付密码和短信验证。
