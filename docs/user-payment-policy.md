# 当前权限配置

按用户要求覆盖原参赛固定规则：订阅列表和费用查询为绿色，自动返回；取消订阅仍为黄色确认。网页账户面板直接展示订阅。

金额门槛按单笔判断，默认1000元；单笔不超过用户门槛为黄色，超过为红色。设置→交易验证规则中可修改，需支付密码。门槛按有数用户隔离持久化；日累计统计仅为历史统计，不参与金额升级。添加银行卡、理财申购、股票买卖与定时转账保持始终双重验证。

修改门槛增加策略版本，短信绑定该版本及交易参数。升级时从旧日累计模式迁移一次，保留资金、交易和已存门槛；不重置后续自定义门槛。旧交易短信和预约授权可能因安全设置更新失效，需重新发起验证。

回归：单笔边界、当日多笔互不累计、自定义门槛持久化、短信失效、订阅查询直接展示且不修改协议、取消订阅仍需确认、定时提前验证与幂等执行；手机320/390/768宽度布局。
