# 联系人关系与 AI 添加

联系人支持家人、朋友、爱人、同事、熟人、其他与未分类；生日、性别、特别关注均可选。在面板点“修改资料”保存，顶部分类按钮按关系或特别关注筛选。旧联系人默认未分类，不猜测关系、性别或生日，原名、备注、电话与银行卡保留。

新增只要求姓名；手机号、银行卡及资料可稍后补充。银行卡仍须同时提供银行名称与完整卡号。没有银行卡的联系人不能用于转账。资料按人员保存，同一个人的多张银行卡共享资料。

对话新增使用 list_contacts 查询同名，再由 create_contact 生成确认卡；用户确认才保存，同名须明确合并或另建。手机号经过模型脱敏时，后台仅恢复当前会话用户明确提供的号码，不编造；所有变更仍复用参数检查与执行回执。保存后通过 contacts.updated 事件刷新已打开的联系人面板。

示例：帮我添加联系人小林，是我的朋友，生日2000年3月4日，性别女，特别关注，手机号13800123456，暂不填写银行卡。

迁移新增 contact_profiles 表，保留当前银行与用户数据。默认未分类、生日未知、性别未设置、未特别关注。各用户数据独立保存。

验证：132 项后端测试通过，最终联系人与模型相关20项检查通过，Ruff、Vue类型检查和构建通过；浏览器验证资料保存和朋友、关注筛选；经用户授权，实际DeepSeek在临时数据库成功完成对话添加和确认保存，没有修改实际账户或资金。
