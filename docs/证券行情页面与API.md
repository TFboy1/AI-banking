# 有数证券：独立行情单页与 AKShare 接入

## 访问

证券站使用独立服务：http://127.0.0.1:8001/ ，行情 API 也位于8001端口。有数银行继续使用8000端口，页面互不链接。

启动证券站：在项目根目录执行 `python -m uvicorn banking.stock_site:app --app-dir backend --host 127.0.0.1 --port 8001`，或运行 `scripts/start-securities.cmd`。关闭8000端口的银行服务不影响证券站。证券服务不初始化银行用户或账户数据库。

这是独立的行情研究页面，具有精选股票、股票搜索、自选、全市场快照、日K线、收盘走势图、5/10/20日均线、成交量及历史表格。自选需要证券手机号短信登录，按证券账号保存；通过同步码一对一关联有数账户。其他股票可以输入六位代码并回车查询；全市场列表展示前120项，可按名称或代码筛选。

## 数据边界

- 真实数据由 AKShare 提供，上游为东方财富或腾讯证券，不生成随机股票价格。
- 页面上的数据源、历史交易日期和获取时间分别显示，历史收盘价不当成当前实时报价。
- AKShare 请求运行在限时独立进程中，单次最多45秒、同时最多两个请求；相同缓存键的并发请求合并。
- 行情快照缓存5分钟，历史行情缓存1小时；失败后60秒内不重复请求。失败时有旧数据则明确显示旧缓存；没有数据则展示空态。
- 缓存保存在 `data/stock-market-cache.sqlite3`，不打入项目压缩包。该数据不包含银行账户、密码或模型密钥。
- 行情接口是公开只读接口，不要求银行登录；银行业务继续沿用原有用户隔离和验证。
- 图表支持不复权与前复权。已支持连接有数账户、同步自选、由银行对话发起模拟买入，并在证券站显示成本持仓与订单；不连接真实券商，不真实下单。详见《证券自选与模拟交易》。
- 数据源可能延迟、变更或限流，页面不保证交易级实时性。使用或对外展示数据，应确认上游的使用范围。

## HTTP API

| 请求 | 含义 |
| --- | --- |
| `GET /api/stocks/catalog?q=平安` | 搜索精选观察名单，不是全部上市公司目录 |
| `GET /api/stocks/quotes?q=000001&limit=100` | 行情快照，支持名称或代码筛选，最多6000项 |
| `GET /api/stocks/000001/history?days=120&adjust=none` | 指定股票的历史日线，5至360个交易日 |
| `GET /api/stocks/000001/history?days=120&adjust=qfq` | 前复权历史日线，用于走势观察 |

响应包含 `status`（ok/stale/unavailable）、`source`、`fetched_at`、`stale`、`error`、`rows`；历史数据还包含 `quote_date`、`adjust`。价格单位为人民币元，成交量统一为股，成交额为元。`simulated=false` 表示来自真实行情适配器；无可用数据时仍需以状态和空列表判断，不代表行情获取成功。

## 安装与开发

项目依赖已加入 AKShare，使用 `uv sync --frozen` 可安装。单独使用系统 Python 的环境可按 `pyproject.toml` 安装依赖。前端构建同时生成银行页面 `index.html` 和证券页面 `securities.html`。
