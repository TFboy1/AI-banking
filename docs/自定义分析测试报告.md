## 详细检查

- 金额：收入、支出、净收支按整数分计算；内部转账、理财、证券买入与卖出本金均排除日常收支。模型计算与后台独立汇总不一致时不展示结果。
- 时间：北京时间跨日与UTC时间换算、开始日与结束日边界、闰日、非法日期、倒置和超长区间、未来流水截断、未结束期间提示。
- 筛选：商户／用途关键词、类别联合筛选；外卖不直接等同全部餐饮。
- 隔离：不同会话不能复用数据集；过期、篡改、删除会话均拒绝使用；计算期间删除会话后不能发布结果。
- 代码限制：导入、文件读取、反射、任意函数、属性访问、循环超预算、复杂结构、超大数值／文字、修改输入、伪造结果均拒绝。未执行分支里的危险函数也拒绝。
- 进程：取消和超时后清理子进程；不传递环境中的密钥；同时最多两个计算进程；排队取消不会占住容量。损坏JSON、错误结果类型、缺失字段或非法执行步数均给出受控错误。
- 恢复：回归现有中断与恢复流程；失败分析留下失败记录，不产生资金流水或确认卡。
- 图表：无数据明确提示；对比基准无正金额时不计算增长率；负数从零轴向左显示；大金额在图内缩写，明细保留完整金额。

## 本轮发现并修复

1. 极端结束日期计算次日时溢出，改为可理解的日期错误。
2. 未执行分支中的任意函数调用未在预检查拦截，增加全代码树调用检查。原解释器也不会实际执行这些分支，本轮补齐提前拒绝。
3. 分析子进程返回损坏或缺字段数据时错误处理不完整，增加响应结构、金额类型与执行步数检查。
4. 负值柱形原本按绝对值向右显示，改成带零轴的正负方向。
5. 大金额挤到环形图中心，改用万／亿缩写；精确金额保留在图例与明细中。
6. 进一步分析按钮原文字包含分类，但指令只分析周趋势，改成与指令一致的“进一步分析每周趋势”。

## 验证边界

本轮证明上述样本和限制下的行为，不代表任意自然语言都能正确理解，也不等于操作系统级安全认证。执行环境是受限Python语法解释器和独立子进程，尚非容器或虚拟机。当前自定义分析主要支持时间、类别、商户／用途筛选及趋势和两期对比；未实现任意统计算法或任意代码执行。

模型表达的实际参数与运行记录另见测试输出“自定义分析扩展自然语言测试.json”。没有记录的区间不能据此断言真实消费为零；不同时长区间的差额不能直接当成同比增长。
