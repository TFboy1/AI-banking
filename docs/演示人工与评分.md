# 演示人工与评分

在当前对话输入“转人工”“帮我转人工客服”等明确指令，或者点击左侧会话列表底部“共用你的模拟账户”旁的电话图标，走同一个后台流程，不调用模型，将对话交给独立管理员工作台。

管理员入口：http://127.0.0.1:8003 ，默认密码 `000000`。启动及审核说明见《管理员人工工作台.md》。

用户转人工时显示等待接入提示，历史记录同步到工作台，等待时可继续留言。管理员接入后双方可互发文字消息。用户或管理员结束服务时显示“请给人工打分”，下方提供五颗可点击的星星。

星星左半边对应半星，右半边对应整星，支持0.5至5星，步长0.5。也支持键盘方向键调节、Home/End选择最低或最高分。评分自动保存，可修改；每张评分卡属于其原对话，刷新或切换会话后恢复，不跨对话共用评分。

如果有任务正在运行或等待确认，先停止后续操作、使旧确认卡失效，保留已完成的交易。此入口不额外发送中断报告，资金核对信息仍保存在原任务状态中。人工服务期间 AI 暂停处理本对话；服务结束后可明确输入“继续”恢复原业务需求，未执行交易仍须重新确认和验证。

评分接口 `POST /api/handoffs/{message_id}/rating` 验证登录、当前用户数据库、会话归属和评分卡类型；使用1至10的整数半星单位保存，拒绝越界或非整数输入。
