# 部分成功任务的收尾

多步骤任务发生失败时，后台依据成功审批回执和已落账流水生成收尾卡，列出已完成操作、扣款与到账金额、未完成DAG步骤及失败原因。纯查询失败或没有成功业务变更时，不生成补偿卡。

- **保留已完成，结束剩余步骤**：不执行资金操作，关闭这份原任务的恢复入口。以后明确提出的新需求仍可办理。
- **重新选择未完成项目**：恢复用户选中的具体检查点，保留成功操作，只重新核对剩余需求；旧报价和旧验证不能复用，新的交易继续经过确认与支付验证。中间查询其他内容不会选错恢复任务。已保留的旅行订单不能在这次恢复里擅自退改。
- **退订此整单**：仅对本任务及恢复链里有成功回执的旅行预订提供。先查询当前订单版本，创建整单免费退订确认卡，重新验证后才原路退款；不直接修改余额。取消退订确认不影响原订单，可以重新选择。退款成功后原收尾卡更新订单状态和退款金额，不支持重复退款。

收尾信息与选择保存在原会话，刷新和重启可查看。按钮携带状态版本，旧页面和重复点击不能反复发起操作。账号、会话、删除状态、人工接管、安全锁和现有交易验证继续生效。选择操作产生事件记录；退款作为独立审批、回执和流水保留。

金额的“原任务已扣款／已到账”是原任务及其恢复链的历史流水，不是消费或当前净损失。之后办理的退订退款单独显示。股票、已成功转账、已下单外卖等不提供通用自动撤销；应另行核对其业务处理方式，必要时转人工。

## 当前旅行订单的边界

当前单笔往返交通和酒店组合在同一个数据库事务里结算，整体成功或整体回滚，不会制造“同一单交通成功、酒店失败”的部分扣款。本功能处理的是多步骤／多笔订单之间的部分成功，不把组合订单拆成三个外部预订，也不宣称存在真实商户的库存锁定或分布式回滚。

当前旅行仅支持整单退订。已退订的成功项目不能继续作为保留订单恢复原计划，需要结束这份任务并明确提出新的安排。
