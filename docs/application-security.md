# 应用注册与密码

首次打开先注册（用户名、手机号、模拟短信验证），再添加联系人（可稍后添加）、设置四位数字密码、再次输入确认。已有账号可通过手机号短信登录；已有密码时可直接解锁。验证码显示在右下角，不发送真实短信。每个手机号对应独立账号；各账号的银行数据、联系人、设置和对话分别保存。

联系人右侧齿轮是应用设置。应用密码默认开启，开关必须验证当前密码；修改已设置的密码属于红色操作，必须验证旧密码和本次修改绑定的模拟短信。关闭应用密码只取消启动解锁，转账、申购、赎回、模拟消费和目标转存仍需交易密码。飞书资金确认需返回 Web 验证，不能绕过。

密码按加盐 PBKDF2 哈希保存，不进入模型或交易回执。改密验证码绑定用户、会话、旧密码状态和新密码，修改成功要求其他会话重新登录。验证码五分钟有效、只能使用一次；重发间隔六十秒；验证码错误五次失效。密码错误五次锁定六十秒。

未登录或未完成引导时，银行接口和事件流受后台保护。仅已短信认证的用户可以使用联系人引导。迁移新增身份、会话和验证码表，不重置银行数据，不代设用户名、手机号和密码。

APP_AUTH_ENABLED 默认 true；业务单元测试显式关闭登录层，独立认证测试保持开启。日常使用保持默认值。

验证：126 项后端测试通过；前端类型检查和构建通过；浏览器验证注册、短信弹窗、联系人引导、密码二次输入、刷新解锁、应用设置和理财赎回密码。

新增账号从空白个人数据开始，仅理财市场的公共产品目录可见。演示文档账号保留更新前的全部银行状态。退出后密码页同时提供注册和手机号登录两个入口。

应用设置中的“个人信息”可以修改用户名（1–40 个字符，不能为空白）。保存后顶部中间的“您好，用户名”即时更新；用户名按账号持久保存，手机号、密码及银行数据不变。
