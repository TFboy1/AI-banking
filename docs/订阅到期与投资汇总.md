# 订阅与投资账户展示

模拟账户的订阅列表提供取消按钮，点击生成聊天确认卡，确认后停止未来代扣，不退款；取消不改变当前服务到期日。到期日按模拟续费日的前一天推算，页面及查询卡明确标注为模拟推算，不是读取真实商户权益。

账户分类中的“投资账户”是只读持仓汇总，金额=本行理财模拟市值+证券剩余持仓成本；已包含在总资产，不新增现金余额，也不能作为付款账户，避免重复支出或重复计入资产。

## 账户余额与银行卡解绑

模拟账户首页的账户总余额=分类账户余额合计+独立银行卡余额合计；总资产=账户总余额+投资持仓。本行理财按模拟市值、股票按剩余成本计入投资持仓，证券账户的行情浮盈亏单独展示。共享日常账户的旧卡不重复计入余额。

删除独立银行卡仅解绑，原余额和预留计划保留在该卡账户，不转入日常账户、不产生内部转账流水。解绑卡从当前已绑定账户统计和付款选项中移除；重新添加同一卡恢复原余额、冻结状态和限额，不重发5000元初始余额。旧版本已发生的划转和流水保持原记录，本次不自动逆转已使用的历史余额。

## 银行卡与分类账户划转

投资账户固定显示在日常账户正下方，只展示持仓金额，不参与分配、改名、删除或现金划转。

分类账户的“转入”从银行卡转入该账户；“提现”将该账户余额转入银行卡。银行卡区域也提供“转入账户”和“从账户转入”。选择银行卡、分类账户及金额后生成确认卡；核对并验证交易密码，按北京时间当日累计转账，累计超过固定1000元门槛还需短信验证。

后端要求一端是当前用户已绑定且正常的独立银行卡，另一端是日常、储蓄或普通分类账户；检查余额、预留资金、卡限额及执行时状态。取消、失败不划款，重复确认不重复记账。两端余额与对应内部流水原子更新，总余额和总资产不变。旧版共用日常账户的银行卡不作为独立余额重复划转。

## 对话创建账户

对话助手使用`create_account_category`工具生成创建确认卡，确认后才写入当前用户数据库并推送`bank.updated`刷新列表；新分类余额为0。手动创建和对话创建共用同名校验与保存逻辑，不允许复制系统固定“投资账户”。取消、过期或重名冲突不会新增分类；重复确认不会重复创建。没有该创建操作的成功回执时，拦截模型仅凭文字宣称创建成功。


## 按预算买入股票与默认收起

模拟账户移除重复的理财持仓栏目，投资账户中的持仓继续保留。卡片、订阅、最近流水初始化为收起。

quote_stock_purchase 每只股票支持 shares 或 amount_yuan（二选一，金额为元的字符串）。后台按最近可用行情换算100股整数手，向下取整，不超过预算；显示预算、实际成交金额、未花费余款。金额不足100股时报最低所需金额，无报价记录、订单或扣款。预算不能同时充当多只股票各自的预算。股数卖出接口保持原规则。买入继续要求R4及以上、确认、支付密码、短信验证，报价五分钟有效，实际扣款使用报价金额。

自动测试覆盖预算边界、非法参数、超出预算防护、金额指令通过聊天工具、报价后实际扣款及既有买卖回归；独立测试页面验证折叠默认状态。行情来自现有证券行情服务，不保证实时成交价格。


## 证券市场搜索、单股价格与对话自选

有数新增 search_securities_stocks、get_stock_price、add_securities_watchlist。身份资料、价格、报价均经独立证券站的授权API获取，有数不读取行情库也不猜价格。非自选股票搜索核对后可报价买入，仍需关联账号、R4、确认、密码和短信；未默认加入自选。

明确要求加入自选时自动执行非资金变更（capability effect=auto），按bank_owner映射当前证券账户，不替换原列表，重复添加幂等，限制20只，服务端记录审计。无执行回执时拦截添加成功声明。证券页切回窗口时重新同步自选。

独立证券API新增：GET /internal/securities/stocks/search?q=名称或代码；GET /internal/securities/stocks/{symbol}/price；POST /internal/securities/{investor}/watchlist/add，body为symbol。均需桥接密钥；用户会话不接触密钥。搜索优先服务已有目录，未命中再查行情快照中的A股名称代码。价格优先最新可用快照，失败时回退最近可用交易日收盘价并明确标注类型、时间、来源；无可用价格时返回错误，不生成数字。买入按历史收盘价模拟，查询快照与实际报价可能不同，确认卡展示成交依据。


## 20只测试股票池

测试股票池统一取 stocks.CATALOG 现有20只，覆盖银行、消费、新能源、半导体、医药等行业。证券页面行情列表、名称代码搜索、自选新增、买入报价和历史查询限制在此池内，仍使用证券服务真实行情。不自动为用户添加20只自选，不删除既有资金或持仓；池内非自选仍可买入。旧持仓卖出流程保留。当前统一100股整手是演示简化，并非所有真实市场的通用规则。
