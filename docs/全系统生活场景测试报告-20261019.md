# 有数全系统生活场景测试报告

测试日期：2026-10-19（北京时间）。

## 结论

当前已实现的主要日常操作可以完成：查询余额、联系人管理、账户与银行卡管理、转账、理财申赎、证券模拟买卖、订阅管理、账单分析、外卖与旅行预订，以及定时、中断恢复、人工服务和安全验证。这个结论限于下面列明的已测范围，不代表任意商户、任意城市或任意自然语言表达都能处理。

本次使用隔离数据库与独立测试账户验证资金操作，没有在现有演示账户执行转账、购买、退款或改设置。公网入口和正式证券行情只做查询。

## 本次修复与维护

1. 修复旧定时授权回执缺少标题或操作编号时，中断/重启恢复汇总可能报错的问题。标题从已有确认摘要读取；缺失的回执编号显示“—”，不编造交易号。只有授权、没有流水时明确显示尚未执行，不重复扣款。
2. 更新旧回归预期：单笔黄色交易不因之前付款升级短信；用户能修改金额门槛；查询订阅不再等确认；证券测试行情包含开盘字段并使用测试时钟。没有为迎合旧测试改回用户已经取消的规则。

## 仍有的范围限制

- AA分摊收款、催收进度等不在现有完整业务流程内。
- 旅行当前以演示城市内的往返交通加酒店组合为主；不能把“只退返程”当成支持单项退订。免费退改指手续费为0，仍需补退差价。
- 外卖店铺和菜单是演示目录；无对应菜品或地区时不能完成真实下单，已支付订单的改餐/商家履约退款也未作为现有能力验收。
- 股票按测试股票池与100股整手规则处理，休市不能买卖；历史行情接口能返回数据不代表已持续验证实时行情稳定性。
- 飞书适配、绑定、回调和支付入口通过自动化验证，本次没有向真实飞书私聊发送测试消息。
- 人脸自动化使用合成特征及画面，语音使用测试音频和浏览器设备模拟；不把这些结果表述为真人识别准确率或每款真机兼容性结论。
- 模型及网络服务可能暂时不可用。此次确实发生过一次连接中断，重试成功；不能承诺任何表达、任何网络状态下都一次完成。
