# 有数三平台功能测试报告

本轮覆盖旅行、证券和外卖，共28组常见自然语言场景，均使用当前配置的大模型和隔离测试账户。最终复测28组通过。

项目全量后端回归357项通过；之后补充并复测了位置省略、退款回执防护、离线账户升级和多来源退款。前端类型检查、生产构建与免费退改页面的浏览器测试通过。

评测不执行真实用户交易。对话评测只到待确认卡；实际虚拟扣款、补退款、密码与短信验证、失败回滚、重复提交、中断恢复和账户隔离由临时数据库测试验证。证券口语评测采用固定测试行情及交易时钟，不代表当前真实股价或实际开市状态。

## 本轮修正

- 旅行出发、返程、入住日期与定时付款分开，普通未来行程可正常生成即时预订确认卡。
- 明确买卖或下单且参数齐全时，查询有效报价后直接生成待确认卡；只比较、先报价或说不要下单时保持查询。
- 股票报价提供后台交易时段状态，模型依据该状态判断是否可交易，避免自行推算星期。
- 用户已明确说陆家嘴、徐家汇等位置时，直接保存对应演示位置并继续搜索；“就第一个”从实际位置列表与历史卡片中解析，不能默认任意地点。
- 旅行订单增加版本保护；旧改签卡、已使用报价、已退订订单不能重复补退款；没有成功回执时拦截虚假的退款、改签成功文本。
- 离线用户也会升级旅行订单结构，不必先重新登录有数才能在独立旅行站查看原订单。

## 免费退改规则

所有演示机票、动车与酒店的退订、改签手续费统一为0。免费指不收手续费，不代表免除新旧方案差价。

| 操作 | 资金处理 |
|---|---|
| 改成更贵方案 | 仅补扣差价 |
| 改成更便宜方案 | 按剩余原支付记录退回差价 |
| 同价改签 | 不扣款、不退款 |
| 整单退订 | 退回剩余全部实付 |
| 付款分类账户已删除或卡片已解绑 | 退款转入日常账户，确认卡显示原因和去向 |

改签更新原订单，未要求更改的部分保持不变；补退款、订单状态和回执在同一事务完成。办理前仍需明确确认及支付密码，超过单笔红色门槛另需短信验证。

## 当前范围

- 旅行支持现有20个演示城市的往返交通加酒店组合；单程、纯酒店、儿童票及真实履约尚未扩展。
- 退订目前为整单免费退订，不支持只退某张票或单个酒店项目；此类请求先澄清，不擅自整单退款。去程、返程或酒店可分别改签，需满足日期和城市一致性检查。
- 外卖已验证查询、点餐、改口、待确认取消和模拟支付；已支付订单的改餐、商家退款尚未扩展。
- 股票仍按测试股票池与整手规则交易，开盘前、午休、收盘后和非交易日不能交易；行情和持仓可查询。
- 28组表达用于验证这次覆盖的场景，不等于穷举所有自然语言说法。必要信息缺失、范围不支持或报价失效时，应补问或停止。
