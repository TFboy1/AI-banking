# 定时转账：提前验证，到点执行

本版为单次预约，支持联系人转账及本人账户、银行卡与分类账户之间的划转。可在 AI 对话中明确提出日期、时刻、对象和金额，也可打开“模拟账户”的“定时转账”新增；列表默认收起。

例如：“明天上午9点，从日常账户给张三转100元。”若联系人同名或有多张银行卡，先澄清收款银行卡。缺少时间不能猜测，定时需求不能替换成即时扣款。时间采用北京时间，最多提前365天。

## 提前授权

先生成授权确认卡，显示金额、收款人、执行时间和授权范围。在验证窗口选择付款账户，并输入支付密码；定时转账统一提前验证支付密码及模拟短信；实际执行时按北京时间当日累计转账再次复核。即时转账累计不超过1000元为黄色，超过为红色，门槛固定。

授权成功只保存预约，不扣款、不冻结余额，不代表已转账。授权时先检查当前可支付条件，到点再检查余额、资金预留、银行卡状态、业务支付限额等。预约与实际交易分别保存回执。

授权绑定执行参数、对象资料、付款账户和安全设置。没有成功授权回执及密码/所需短信验证记录不能创建有效预约；不会保存明文密码、短信验证码，也不会在到期时重复使用验证码。

## 到点执行

后台每秒检查到期预约。多用户主服务直接处理所有用户的数据库，即使该用户未打开页面或未登录也可执行，且不需要调用模型。参数摘要、收款卡资料、付款账户、身份安全版本均须与授权时一致，再按当前业务状态检查后原子扣款、记账并生成实际交易回执。

同一笔预约的转账、流水、回执及最终状态在同一数据库事务中提交。并发调度、重启或重复扫描不会重复扣款。处理中意外退出而尚未提交时全部回滚，重启后可安全重新检查。

后台需要持续运行。计划时间之后5分钟为执行窗口；若短暂停机后在窗口内恢复，可继续核对并执行。超过窗口则停止并要求重新授权，不会晚很久突然补扣。余额不足、卡片不可用、安全锁定等会停止并记录原因，不自动重试；修改支付密码、手机号、安全门槛或触发安全保护后，原授权失效。

## 查看、修改、取消

列表显示待执行、成功、失败、取消及需要重新授权，保留失败原因与实际回执编号。聊天可查询或取消预约。

修改收款人、金额、付款账户、时间或备注需要新确认和验证。新授权成功后原预约才取消；验证期间原预约仍有效。若原预约已先执行，修改申请会失败，避免再次转账。失败或授权失效的预约可重新选择未来时间并授权。

执行前可取消预约；取消不撤销已完成交易。删除原对话会使到期预约停止。演示重置同时清除预约，避免旧任务之后扣款。

## 审计及测试

原授权及实际执行均进入管理员操作审计，只有实际流水计入扣款、到账汇总；授权金额不会被计为消费或已扣款。支持后台事件通知和页面列表同步。

测试使用独立临时数据库，覆盖密码与红色短信、授权不扣款、并发及重启防重复、参数篡改、余额/对象/安全设置变化、取消与重新授权、多账号隔离、离线用户调度和实际页面操作。不接入真实银行资金。
