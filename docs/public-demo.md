# 公网演示入口

同一 ngrok 域名按路径代理到各独立服务；账号和数据库保持独立。

- 有数：https://your-domain.example/
- 证券：https://your-domain.example/securities/
- 外卖：https://your-domain.example/food/
- 旅行：https://your-domain.example/travel/
- 客服：https://your-domain.example/admin/

各网站服务需先启动（8000、8001、8002、8003、8004），在PowerShell设置 `$env:PUBLIC_ORIGIN="https://your-domain.example"`，再运行 `python scripts/public_gateway.py`（仅监听127.0.0.1:8010），最后运行 `ngrok http 8010 --url https://your-domain.example`。不要同时启动相同域名的两个隧道。关机或停止隧道后无法访问。

网关校验写入请求来源，限制各子站只能访问自身公开接口，阻断子站内部桥接地址；平台登录 Cookie 分路径保存并过滤转发，公网 Cookie 添加 Secure。银行根路径保留流式响应和原飞书支付地址。客服接口仍由管理员会话鉴权。这里没有独立域名级的同源隔离，同域名下的代码应作为共同信任边界。

飞书普通消息使用单独的“飞书”对话，每个有数用户独立保存；绑定和后端启动时保证创建。旧消息、交易和审计记录保留原处。通知卡片选中后将通知上下文带入飞书专用对话；原卡片的确认、暂停等仍绑定原任务。删除飞书对话后再次收到消息会新建。

手机应用设置：标题及关闭按钮位于滚动区域外，只允许纵向滚动；个人信息直接显示，密码、交易规则、安全恢复、日报、平台同步、飞书和模型默认折叠。

飞书接收回执：已绑定的文本请求在同一事务先写入持久化回执队列，再创建任务；发送器按队列顺序先发纯文本“有数已收到，正在处理你的需求。”。重复事件不重复回执；回执发送失败使用既有有限重试，不重做业务。桥接不再重复发送成功接收提示。
