# 本人人脸与交易验证

`.env`总开关`FACE_ENABLED=true`默认开启。改为`false`并重启后端可关闭人脸：黄色使用密码，红色保留密码与短信；绑定、换绑、摄像头验证接口同时停用。已有加密档案保留，重新开启后继续使用。切换会废弃未用的人脸凭证、验证挑战和交易短信，需重新获取；不能通过旧刷脸凭证绕过密码。

账户设置中另有人脸验证开关，默认开启。关闭必须验证已绑定本人面容、支付密码及短信，单纯提交“关闭”参数不能生效；关闭不删除人脸档案，重启服务器也不会恢复开启。重新开启需验证支付密码、短信和已绑定本人面容；未绑定时“开启人脸”直接进入录入，录入成功自动开启，解绑成功自动关闭，若服务器总开关关闭则不能从页面开启。账号偏好互相隔离。配置变化会使未使用的交易验证失效。

新账号完成联系人和支付密码设置后，会提示录入人脸，可选择“暂时跳过”。跳过状态持久保存，不会每次登录重复弹出；没有绑定人脸时黄色使用密码，红色使用密码和短信；支付窗口不显示绑定入口。已有账号不强制重新走注册引导。

绿色查询无需验证。黄色资金操作优先刷脸，成功即可执行；未绑定、验证失败或主动切换时可以使用支付密码。已绑定且开启人脸时，红色操作必须人脸、支付密码、模拟短信三项全部通过；未绑定或关闭时，红色仍需支付密码和短信，不强制刷脸或跳转绑定。单笔门槛沿用用户设置，默认1000元。注册首次设置密码除外；之后修改密码也需要三项验证。

设置→人脸验证：明确同意后，验证密码和模拟短信，通过随机动作核验录入一位本人的特征。换绑、删除必须先验证已绑定人脸。删除后交易不再要求人脸，仍按风险等级验证密码和短信；无法验证原人脸时联系人工处理，客服目前不直接提供绕过原人脸换绑的接口。

这是一对一比对，证明与注册面容一致，不证明法定实名身份。没有跨账户搜脸、身份识别、照片上传或管理员读取人脸特征接口。每用户数据库隔离，只返回已绑定状态。人脸模板和临时挑战特征使用Fernet加密，密钥在各用户数据库旁的`.face.key`文件，需与数据库分开保护，生产部署应改用独立密钥服务。原始画面仅在请求内存里处理，不记录照片、视频、特征或完整凭证到日志。删除面容会删除模板、待用验证凭证和临时挑战；密钥丢失时停止验证，不能自动重建绑定。

摄像头使用HTTPS和用户授权，关闭、取消、切后台、权限迟到时立即停止摄像头音轨。仅首次录入及重新录入新面容时，后台下发随机“正脸→左右转头随机顺序→正脸”，每阶段需两幅不同画面，后台判断动作、画质、唯一人脸和连续身份。交易、修改密码以及关闭、删除、换绑前的原人脸核验只需正对摄像头，以两幅不同画面匹配已绑定模板，不要求转头。镜像预览中的左右提示与原始画面方向相反，判定已按镜像方向处理，并拒绝明显歪头替代转脸。正脸SFace余弦阈值0.45，转脸连续身份检查阈值0.30，回正后再次按0.45核对，减少角度变化误拒。MiniFASNet静默分数仅作辅助参考，不再因单帧低于0.80就中止动作；动作核验完成且身份匹配才通过。这是为减少当前摄像头场景误拒而采用的演示模式：录入时固定正脸不能通过；交易时只作正脸身份比对。照片透视变形、视频重放、虚拟摄像头、深伪仍可能绕过，不能用于真实金融交易或称为银行级活体认证。红色密码及短信要求不变。

验证挑战120秒，单次交易凭证90秒、绑定会话/操作参数/付款账户/安全规则/人脸版本且只可消费一次。后台在实际确认时检查；改账户、金额、时间或验证规则需重新验证。定时交易在授权时验证，到期沿用既有授权/复核机制。重复确认已成功操作仍返回原回执，不会重复扣款。人脸失败连续5次沿用交易暂停60秒及多次熔断人工解锁规则。画质与姿势提示不当作密码错误计数。模型不可用时红色停止，黄色可改用密码。

## 安装与来源

`uv sync --frozen --extra speech --extra face`，然后在根目录运行 `uv run --extra face python scripts/setup_face.py`。模型路径可用`FACE_MODEL_DIR`覆盖。初次部署约43MB模型，默认CPU推理。代码、模型和许可证的固定Git版本及SHA256见`scripts/face-models.json`，下载后校验。

- OpenCV Zoo YuNet (MIT) / SFace (模型目录Apache-2.0)：https://github.com/opencv/opencv_zoo
- MiniVision Silent-Face-Anti-Spoofing (Apache-2.0)：https://github.com/minivision-ai/Silent-Face-Anti-Spoofing
- MiniFASNet架构保留在`backend/banking/vendor/minifasnet.py`，原许可证同目录；预训练权重许可证随安装保留。代码和模型分别保留来源，比赛材料需注明使用这些开源组件。

自动化测试使用合成特征检查权限、绑定、失效、防重放和账户隔离；实际模型仅测试加载和空白画面拒绝。不会替用户录入人脸，不以模拟特征测试冒充真人准确率、活体防伪测试结果。

取景区域与界面椭圆框一致：上传画面按实际预览比例及contain留边绘制；后台按同一中心和半径筛选框内唯一人脸，框外旁人不参与身份比对。脸过小、过大或超出框边界时仅提示调整位置，不推进验证步骤。

录入及换绑后的新面容采集失败不计入安全状态，允许不限次数重新尝试；采集过程身份变化时重置到第一步继续，成功录入也不会清除已有交易人脸失败计数。交易及已绑定人脸的身份核验不匹配仍计入安全失败记录，沿用熔断规则。画质、距离与姿态调整提示不算身份核验失败。会话有效期与服务请求频率限制仍保留。
