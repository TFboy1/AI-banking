# 管理员人工工作台

有数用户页为 http://127.0.0.1:8000 ，独立人工服务工作台为 http://127.0.0.1:8003 。

运行 `scripts\start-admin.cmd` 启动工作台；需要先构建前端（与有数共用一次前端构建，分别输出入口）。默认管理员密码为 `000000`，密码散列保存在 `data/admin.sqlite3`，与用户支付密码独立。管理员登录有效8小时，连续5次密码错误暂停登录60秒。会话使用 HttpOnly / SameSite=Strict cookie，接口校验来源，不开放跨站访问。

用户在任意对话输入“转人工”，或点击原有电话按钮，系统停止当前 AI 任务、取消尚未完成的确认操作，创建该用户、该对话的人工服务单。已成功交易及回执保持不变。完整历史记录在管理员选择该服务单后展示。用户可以在等待期间留言。管理员点击“接入对话”后双方可互发文字消息，用户页标注“人工客服”。当前实现为文字聊天，不包含音频通话。

人工服务期间普通消息不会触发模型或执行银行工具。管理员只可接入、回复、结束服务及审核解锁，不可代用户执行资金交易。任一方结束服务后出现五颗星、支持半星的评分，独立保存在该段对话。之后用户可继续与 AI 交流；中断任务仍须重新核实、确认及支付验证，不重复执行已完成交易。

人工会话、聊天消息、接入和关闭记录保存在各用户数据库。工作台根据账户目录解析用户，接口不接受文件路径。不同用户与不同对话不能混用服务单编号。删除的对话不能继续接入或回复。服务记录及登录会话可跨进程重启保留。工作台每2秒刷新服务列表，人工期间用户页每2秒同步聊天；这不改变证券行情仅在开盘、收盘更新的规则。

系统安全锁定后仅保留人工申请和人工聊天。解锁申请自动进入工作台并建立人工服务单。管理员在“解锁审核”填写审核说明后通过或拒绝；通过后清除该账户的熔断锁定和相关错误计数，应用仍需重新解锁，未完成交易不会自动执行。通过、拒绝、查看历史、接入、回复及结束服务均记录审计。

可验证：未登录不能读取列表；默认密码登录；历史记录完整；接入前不能发客服回复；用户留言及客服回复双向可见；人工期间模型不运行；结束后可半星评分；跨账户服务单不能串用；重启仍可恢复服务；锁定用户只能聊天，只有管理员可审核恢复。
